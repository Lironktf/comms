Live on Base Sepolia

An AI agent pays an API. Nobody can tell which agent.

The agent pays a real x402 API from a shielded pool, using a zero-knowledge proof. The merchant gets USDC. Base's public ledger shows the pool paying the merchant, but not who paid, their balance or their history. The proof also enforces the agent's spending policy.

Each run makes about 2 real testnet transactions and takes 20 to 30 seconds. The merchant refunds every payment, so the demo stays free.

    What the chain shows, and what it doesn't

    Public on Basescan

    • After a run: the transaction, the sender and the USDC transfer.

    Private, never on chain

    • Which agent or person paid
    • Which deposit funded it, and the payer's balance
    • The agent's policy: caps, allowed categories, remaining budget
    • Any link between this payment and the payer's other payments

    How it works

    1. The agent calls the API and gets 402 Payment Required back: price, merchant address and the payment scheme.
    2. It builds a zero-knowledge proof (Noir, UltraHonk) that it owns some unspent note in the pool, from a deposit that passed compliance screening, and that this payment fits its policy: a Grayr-verified merchant, an allowed category, a per-payment cap and its daily budget. The proof doesn't say which note is the agent's.
    3. The facilitator checks the proof by simulating the pool call. The amount, merchant and request id are fixed inside the proof, so the facilitator can't redirect the payment.
    4. The pool contract verifies the proof on chain, marks the note spent and pays the merchant. The relayer submits the transaction and pays the gas, so the payer's address never appears.
    5. Refunds stay private too. The merchant refunds by request id. The money comes back as a new note only the payer can open.

    Try the API yourself: curl -i /api/weather returns a real 402 with the payment terms.

    About this demo. It runs on Base Sepolia, a testnet, with test USDC. The contracts are unaudited research code. To keep it one click, the demo agent's keys live on the demo server, so the proof is built there rather than in your browser; in real use the agent builds it on its own machine. The merchant here is also the demo operator. With only a few deposits in the pool, the privacy is weak: it gets stronger as more people use the pool.
